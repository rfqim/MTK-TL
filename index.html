1. Komponen Vektor Dorongan (v⃗):
vx = |v⃗| · cos(θ) = 24.7 m/s
vy = |v⃗| · sin(θ) = 24.7 m/s
2. Besaran & Sudut Vektor Awal:
|v⃗| = √(vx² + vy²) = 35.0 m/s
θ = arctan(vy / vx) = 45.0°
3. Efek Perkalian Skalar (k · v⃗):
k · v⃗ = 1.0 · (24.7, 24.7) = (24.7, 24.7)
4. Penjumlahan Vektor (Total + Angin):
v⃗total = k·v⃗ + w⃗
v⃗tot = (24.7, 24.7) m/s
Besaran |v⃗tot| = 34.9 m/s
